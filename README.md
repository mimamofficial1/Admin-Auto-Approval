# Mrn Officialx Join Request Acceptor Bot

**A Advance Join Request Accept Bot Which Can Accept Both All Pending Join Request And New Join Request.**

## How To Deploy

#### Environment Variables

- <b>`API_ID` : Get From [my.telegram.org](https://my.telegram.org)
- `API_HASH` : Get From [my.telegram.org](https://my.telegram.org)
- `BOT_TOKEN` : Get From [BotFather](https://telegram.me/BotFather)
- `DB_URI` : Mongodb Database Url
- `ADMINS` : Admin/Owner Id For Broadcasting Message.
- `LOG_CHANNEL` : Log channel id start with -100xxxxxx</b>

#### Commands To Use Bot

- <b>`/start` : Check bot is alive or not, know about bot
- `/accept` : Accept all pending requests from channel or group.
- `/broadcast` : Reply this command to your broadcast message in bot.
- `/stats` : Check total users in database.
- `/clean` : Remove blocked/deleted users from database.</b>
